# 🤚🏼 hansen.ai

Site para divulgação do projeto de pesquisa em Inteligência Artificial voltado ao apoio no diagnóstico, monitoramento e tratamento da hanseníase.

## 📌 Sobre o projeto

O **hansen.ai** é uma iniciativa desenvolvida no contexto do dotLab Brazil, com foco na aplicação de técnicas de **Machine Learning** e **Ciência de Dados** para enfrentar desafios da saúde pública, especialmente doenças negligenciadas.

O projeto busca utilizar dados clínicos e históricos para:

- Apoiar o diagnóstico precoce da hanseníase
- Monitorar a evolução do paciente
- Prever resposta ao tratamento
- Auxiliar profissionais de saúde na tomada de decisão
